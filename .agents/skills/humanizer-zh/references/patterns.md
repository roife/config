# 中文编辑对照

以下现象用于定位阅读障碍。单个词、标点或句式不足以判断作者身份。保留符合文体且意思准确的用法。

| 常见现象 | 编辑时看什么 |
| --- | --- |
| 夸大意义、罗列媒体报道、宣传口号 | 哪句话交代了事情本身？删去站不住的赞语，保留有出处且相关的评价。 |
| 句尾硬加影响、泛称专家、套用挑战与展望 | 原稿是否给出了因果关系、具体来源或实际计划？保留证据和不确定性。 |
| 抽象高频词、刻意绕开“是”、同一术语反复换词 | 换成原稿中明确的人和动作，同一概念用同一名称。 |
| 否定式排比、硬凑三项、虚构“从……到……”的范围 | 并列项各自有信息就保留，删掉重复铺垫，避免改动完整枚举。 |
| 密集破折号、加粗、带标题的列表、装饰表情 | 版式应帮助读者辨别层次。操作步骤、警告和原作者惯用的表达可以保留。 |
| 英文标题大小写、引号样式 | 按稿件语言和既有排版处理。保留引文和代码中的字符。 |
| 对话客套、知识截止套话、过度附和 | 去掉误留在成稿里的聊天用语，保留与结论有关的日期和资料局限。 |
| 填充短语、层层限定、通用乐观结尾 | “在这个时间点”可写成“现在”。一句保留一个有意义的限定，末段留下原文已有的结论。 |

用户要求评分时，沿用五项各 1–10 分的量表。直接性看要点是否容易找到，节奏看句子是否好读，信任度看解释是否适合读者，真实性看口吻是否符合作者，精炼度看是否仍有重复。总分 50，45–50 为优秀，35–44 为仍可改进，低于 35 应重审。评分衡量编辑质量，不代表作者身份的概率。

模式来源见 [Wikipedia 写作特征指南](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing)。翻译与工具来源见[项目说明](../README.md)。
