# 中文润色

先看这段话是谁写给谁的、读者读完需要知道什么。用户指定了改动范围、文体或输出格式，就按其要求处理。能从原稿判断语气时直接动笔。

沿用作者的立场、称谓、术语和已有的个人声音。优先改妨碍理解的句子。删去重复评价，把原稿已有的主语、动作和结果放回句子里。保留有用的背景、限定条件和引用。口语里的停顿、说明书里的并列步骤，都可以有意保留。

事实以原稿或用户给的材料为准。模糊归因可以标出待核实之处，不能自行补上机构、数字、经历或他人反馈。润色后对照原稿检查，尤其注意把“可能”改成“会”、把目标写成成果、把团队判断写成作者亲历等含义变化。

例如，原句“我们上线了批量导出功能，旨在赋能用户高效地完成多份报表的导出”可以改成“现在可以一次导出多份报表”。若原稿说的是“准备上线”，就保留这个时间状态。

改稿时直接交付可用的完整修订稿。只要求审阅时，指出影响读者的原句、问题和局部改法。需要解释某种写法或按原量表评分时，查阅[写作模式与评分维度](references/patterns.md)。
